# 阵型可视化与分层分析优化

更新日期：2026-10-06。

## 1. 网页验收入口

访问 `http://localhost:4173`，进入“项目 → 五分钟阵型可视化复盘”，打开视频，再选择右侧“队形空间”。

- 点击“查看阵型分布”或片段缩略图：主视频暂停到代表时刻，显示真实球员检测框与站位连线。
- “分布标注 / 原始画面 / 战术片段”分别显示标注图片、同一帧的原图、同镜头约 4 秒的标注短片。
- 关闭标注、切换分析分类、操作主时间轴或恢复主视频播放：隐藏阵型证据。
- 平时仍播放完整五分钟的人物/足球框选视频，没有给整片永久叠加阵型图，也没有增加自动停顿。
- 原有球员编号与个人选段功能保留，默认关闭。

## 3. 技术流程

```text
原视频 + 已有 GSR 人员框/球场坐标/球队身份 + 镜头边界
  -> 排除非有限坐标、场外坐标、重复 ID、异常人数
  -> 一维聚类划分纵向站位线
  -> 保留真实人数和真实 track ID，不将 7 人比例换算成 10 人
  -> 同镜头前后 2 秒采样，核对分线稳定性、宽度、纵深和线距
  -> 球衣颜色一致性筛查 + 本样例代表帧视觉复核
  -> 原画面检测框与连线、原图对照、短片和结构化证据
  -> 前端按需显示，退出阵型查看即隐藏
```

只有十名外场球员、模板人数准确匹配、时间支持充分、空间展开合理、采样中能观察到门将方向依据时，证据模块才使用“某阵型候选”。仍不称为已确认阵型。未达门槛时用“可见分线”表示，分线数字之和就是该帧实际观测人数。

支持比例表示窗口内几何分组重复出现的比例，不是识别准确率。球衣筛查只是质量过滤，不是重新训练的分类模型；深色球衣的白色号码、遮挡和低清晰度仍会误导它。本轮保留了这个失败案例及复核记录。

## 4. 分层推进的 DONE

| 层面 | 本轮改动 | 尚不能声称的能力 |
| --- | --- | --- |
| 基础事件 | 普通位置静止后开球不再默认判任意球；类型不明保留 unknown | 仅凭球出界不能完全确认角球、球门球或任意球 |
| 定位球落点 | 同一接球队员至少 3 个连续有效样本、跨度至少 0.12 秒；轨迹间隔超限中断；场外球不计稳定控制 | 这是后续控制代理，不是三维第一落地点或开球质量评分 |
| 门将事件 | 只关联动作时刻之前的射门；没有射门依据的接近/控球不再使用扑救类别；移动速度按实际起点到动作时间计算 | 未新增经专项训练的侧扑、高空接球或动作规范性模型 |
| 统计 | 前端人工确认/拒绝同步影响已采纳数、动作类型计数和定位球次数/列表 | 是当前已展示和复核节点统计，不是整场完整统计 |
| 进攻组织 | 基于已复核节点的链路不跨已知切镜，也不把未知镜头边界当连续；来源被拒绝后提示重新复核 | 该约束针对 reviewed_layers 及其前端展示，不代表所有底层轨迹分析器已经实现镜头隔离 |
| 队形空间 | 真实框线图、原图对照、标注短片、可选图层、多人可见性与时序门槛 | 未补全画外球员，未确认整场固定阵型，也未完成标定精度评测 |
| 新视频工作流 | 新视频正常处理结束后生成阵型证据并返回前端；五分钟相同素材无 API 缓存路径优先读取本版 | 本轮没有重新跑完整 GPU 检测链；测试复用了既有 GSR 输出 |

本轮对完整五分钟既有 GSR 数据重跑了 19 个分析器，得到 213 条候选发现、643 个候选事件；报告在 `algorithm_report/`。这些未经逐一核实，不能当官方比赛统计，也没有直接用它们替换网页原有 18 个复核节点。

## 6. 复现命令

```bash
conda activate sports
python -m workflows.visualization.build_formation_evidence \
  --video soccer_input_dataset/test_5min.mp4 \
  --gsr-json soccer_input_dataset/outputs/test_5min_layered_v2/identities.json \
  --bundle soccer_input_dataset/outputs/test_5min_layered_v4/layered_analysis.json \
  --tracking-json soccer_input_dataset/outputs/test_5min_player_focus/player_tracks.json \
  --review-json review_annotations/test_5min_formation_frames.json \
  --output-dir soccer_input_dataset/outputs/test_5min_formation_focus

python -m unittest discover -s tests -q
cd web_preview
node --test scripts/test-review-state.mjs
npm run dev -- --host 127.0.0.1 --port 4173
```

网页运行后，另一个终端在 `web_preview` 执行 `node scripts/verify-formation-focus.mjs`。测试需要本地 Playwright Chromium；默认路径与现有项目测试脚本一致。

本轮验证：98 项 Python 测试、2 项 JavaScript 统计/链路测试通过；前端构建通过；Playwright 桌面与手机的图像非空、片段实际播放、原图切换、关闭/切页/拖动隐藏与无水平溢出检查通过。测试通过只说明逻辑和交互达到这些用例，不代表足球识别精度已被量化。
