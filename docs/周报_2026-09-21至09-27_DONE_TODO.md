## 3. DONE：本周完成

### 3.1 深化有球组织分析

新增可复用的事件组合规则，并结合切片画面审核输出3段组织分析。

| 方向 | 实现方法 | 当前五分钟样例 |
| --- | --- | --- |
| 拉边传中 | 同队相邻 `pass -> cross` 事件，结合时间间隔筛选 | 白队短传拉边后传中，争顶后外围再次接应 |
| 持球推进 | 已采纳 `carry` 节点作为推进片段入口，再看前后组织与回追 | 蓝队中路连接后向禁区方向推进 |
| 门将参与组织 | 同队相邻门将 `foot_pass -> foot_pass` 节点 | 蓝队门将与后卫之间的后场循环出球 |

已加入的限制：

- 相邻连接要求同队、事件已获支持且未被用户拒绝，默认最大间隔12秒。
- 未知队伍、未采纳的中间节点、重启事件及已知镜头编号变化会阻断相关连接。
- 尚无镜头编号时，不把规则输出视为已确认的连续镜头；需要画面审核补充。
- 单个推进节点只是分析入口，不包装成完整进攻链。
- 输出保留来源事件ID，不从稀疏节点推断全场传球次数、控球时长或进攻成功率。

### 3.2 增加空间数据质量检查

在空间候选的代表时刻前后各1秒检查球与双队球员可见性：

| 检查项 | 当前实现 |
| --- | --- |
| 观测帧覆盖 | 至少达到预期帧数的50% |
| 有效球员 | 以唯一跟踪ID统计，双方各至少6名具有有效场内坐标的外场球员 |
| 足球 | 具有有效场内二维坐标 |
| 连续支持程度 | 至少70%的观测帧同时满足人数与足球条件 |

本次8个空间候选均未通过这套可见性门槛。因此，新版没有将精确阵型、线距、人数比当作可信结果发布，而是依据画面保留有限的定性观察。

可见性检查不等于场地标定准确性检查，也不能证明球衣分类和跟踪ID正确。

### 3.4 增加战术评语和证据联动

前端新增四部分评语：

| 展示内容 | 作用 |
| --- | --- |
| 画面观察 | 说明实际可见的人、球与动作过程 |

### 5.1 自动审核与评语接入的边界

- 当前逐片审核是在本次交互中完成，不是网页上传后自动运行的服务。
- 新视频不会自动调用当前聊天中的助手，也不能直接复用本样例的审核意见。
- 后续需先明确审核执行方式：可调用的视觉服务、离线复核任务或人工审核，再封装统一结果接口。
- 自动生成评语必须引用对应图片、时间窗口和事件，不得以流畅文字替代缺失证据。
- 审核失败或证据不足时保留候选与待确认状态，不自动输出确定结论或编造置信度。

### 5.2 暂不作为成熟功能交付

- 精确全队阵型、完整22人空间控制和持续无球跑动分析。
- 全场PPDA、反击效率、传球成功率等依赖完整事件链的正式统计。
- 经过概率校准的真实xG/xA。
- 越位确定判罚、门将扑救成功率和教练级动作规范性评分。

项目中即使存在这些方向的候选或代理指标，也不能将其等同于完成验证的专业能力。
