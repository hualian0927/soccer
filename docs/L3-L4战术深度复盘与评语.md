# L3-L4 战术深度复盘与评语

更新日期：2026-09-22

## 本轮交付

网页项目：**五分钟战术深度复盘**，地址 `http://localhost:4173/`。

继续沿用四层框架，没有另造 L5/L6：

| 层级 | 本轮内容 | 边界 |
| --- | --- | --- |
| L1 事件 | 保留18个复核节点；更正与观察文字矛盾的队伍字段；增加复盘建议 | 不是整场完整标注 |
| L2 统计 | 仅采纳支持或改判节点，排除错误候选；补充动作子类型聚合 | 不计算全场成功率、xG或PPDA |
| L3 有球组织 | 短传拉边后传中、持球推进、门将参与后场循环组织 | 3类可复用规则，输出稀疏证据链，不假设完整控球 |
| L4 无球空间 | 8个空间候选复核：局部收缩与保护3个改判，阵型2个待核实，多打少3个不采纳 | 未经验证的精确阵型、线距、人数比不作为结论 |

主视频沿用原片加人物与球框，不重新检测、不叠加评语、不额外复制90MB视频。
原项目及旧版输出保留。新结果在 `soccer_input_dataset/outputs/test_5min_layered_v4/`。

## 技术实现

- `tactical_analysis/reviewed_layers.py`：基于已复核事件的同队、类型、邻接时间和已知镜头约束生成组织候选。拒绝、未知队伍、超时、已知切镜及重启会阻断相关连接。
- 规则支持的具体模式为 `pass -> cross`、单个已复核 `carry`、相邻同队门将 `foot_pass -> foot_pass`。携球节点只是推进主题入口，不冒充完整进攻链。
- 空间检查在代表时间前后各1秒，以唯一ID统计有效场内外场球员。观测帧覆盖率至少50%，且至少70%的观测帧满足双方各6人及有效足球坐标，才通过可见性筛选。
- 上述检查不证明标定、球衣分类或ID正确，即使通过也不自动发布精确空间结论。未通过时保留有画面依据的定性描述。
- `prepare_layered_review_evidence.py`：为3个组织与8个空间窗口重新取图和剪片，覆盖原候选区间并前后扩展5秒。每窗口抽21张，实际审核偶数索引11张，共121张；不是每一帧都被审核。
- `review_annotations/test_5min_layered_v4.json`：逐窗审核意见与本轮队伍修正，绑定源视频和上一版报告SHA256，不能直接套用其他比赛。
- `build_reviewed_tactical_layers.py`：融合组织规则、可见性检查与审核意见，导出分层JSON和Markdown。

审核由本轮交互中的视觉助手完成，不调用DeepSeek或其他外部API。后台注释文件保留真实审核来源供追溯；前端不显示供应商名称，使用“智能复核”“智能分析参考”。不冒充人工教练或专家标注。

## 前端体验

1. 项目中进入新版本，L1查看事件及评语。
2. 切换L3/L4，点击片段封面或播放图标，主视频跳到对应原片时间。
3. 视频下方展示该片段的画面观察、战术解读、复盘建议、判断边界。
4. 展开复核依据可查看实际审阅的时序图片；完整上下文片段可独立播放。
5. L4可筛选采纳、未采纳和待核实，排除项不伪装成有效技战术结论。

评语中的战术解释是基于可见证据的推断；建议是复盘关注点，不是已经发生的事实或专业评分。

## 运行

```bash
conda activate sports
python prepare_layered_review_evidence.py --bundle soccer_input_dataset/outputs/test_5min_assistant_review_v3/layered_analysis.json --output-dir soccer_input_dataset/outputs/test_5min_layered_v4
python build_reviewed_tactical_layers.py --bundle soccer_input_dataset/outputs/test_5min_assistant_review_v3/layered_analysis.json --annotations review_annotations/test_5min_layered_v4.json --output-dir soccer_input_dataset/outputs/test_5min_layered_v4
cd web_preview
npm run dev -- --host 127.0.0.1 --port 4173
```

若4173已被占用，应选其他端口。输出引用上一版本地证据文件，不应单独删除被引用的素材目录。
