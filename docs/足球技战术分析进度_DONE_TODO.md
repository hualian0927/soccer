## 2. 当前总体结论

### 2.1 已经完成的主线

项目已经形成以下基础闭环：

```text
比赛视频
  -> 球员/足球检测与跟踪
  -> 球队、裁判和门将身份
  -> 球场坐标与比赛状态
  -> 事件时间轴
  -> P0-P3 技战术指标
  -> 中文报告与多标签高光清单
  -> 完整分析视频与高光片段
```

优先级总表中的 P0、P1、P2 共 15 项能力均已有代码入口和输出数据，即**功能覆盖达到 15/15**。P3 的动态多打少、高位逼抢/PPDA、防守空档和攻防转换速度 4 项也已形成候选分析器，即**P3 候选功能覆盖达到 4/4**。

### 2.2 尚未完成的核心问题

当前最大的缺口不是继续增加指标数量，而是把已有候选指标做准：

- 缺少覆盖多场比赛的人工真值评测集。
- 足球小目标仍有漏检、漂移和轨迹中断。
- 转播切镜会造成球员 ID、球队身份和球场坐标不连续。
- 射门、传球、定位球和门将事件仍以视觉规则代理为主。
- 尚未接入官方进球、射正、助攻、犯规、换人等比赛结果标签。
- 正式 xG、xT、Pitch Control、无球跑动和复杂战术识别尚未进入成熟模型阶段。
