# 完整功能清单与实现边界

更新：2026-10-09。网页的“关键事件 / 数据统计 / 进攻组织 / 队形空间”对应 L1-L4 展示层；P0-P3 是研发优先级，两者不是同一分级。

## 基础感知

| 功能 | 当前方法/代码 | 边界 |
| --- | --- | --- |
| 人/球检测跟踪 | YOLOX、DeepEIoU、OSNet，`inference_soccernetGSR.py` | 遮挡、低清、切镜会丢失/换 ID |
| 球场二维映射 | `kpts.py`，关键点/线与场地几何 | 飞行中的足球不在地面，映射不等于三维轨迹 |
| 队伍/裁判/门将 | 球衣上身颜色、轨迹投票、CLIP/身份复核 | 蓝白、号码、阴影仍可能混淆 |
| 球召回补强 | 大小/运动/光流约束、Ultralytics 补检 | 球员/广告误检仍需处理 |
| 替代球检测 | `API/` RF-DETR + Global SAHI + TCN，`ball_detection_adapter.py` 适配 | 补全点不等同于真实检测；专用权重另备 |

## 19 个统一分析器

下列主要输出为可复核的视觉代理或候选，不是经人工真值验证的官方比赛统计。

| 分析器 | 功能 |
| --- | --- |
| `data_quality` | 足球覆盖、可见人数、坐标质量等数据门控 |
| `event_timeline` | 触球、接球、传球、推进、射门、角球和球权转换候选；射门区域/角度/压力结构 |
| `ball_out_of_play` | 越过边线/底线候选，不直接确认重启类型 |
| `defensive_interventions` | 对抗、干预等基础防守候选 |
| `spatial_structure` | 区域占用、平均位置与空间结构 |
| `team_shape_engine` | 宽度、纵深、三线高度/间距、面积与紧凑度 |
| `formation_tendency` | 站位聚类、模板倾向与代表帧，人数不全时局部展示 |
| `relational_space` | 人员关系、局部空间几何 |
| `set_piece_delivery` | 重启、开出位置、后续控制/落点代理 |
| `goalkeeper_interventions` | 门区球-门将持续接近、控球和射门干预候选 |
| `phase_of_play` | 后场组织、中场推进、前场进攻等规则阶段 |
| `progression_analysis` | 传球方向/距离、短长传/传中/直塞候选、推进/穿线 |
| `attacking_chains` | 从射门回溯可见进攻链与组织类型 |
| `defensive_third_risk` | 防守三区/通道风险片段排序 |
| `pass_network` | 有向传球网络、中心性、连通性、熵 |
| `numerical_superiority` | 局部多打少与持续人数优势候选 |
| `pressing_analysis` | 高中低位压迫、参与关系及 PPDA 代理 |
| `defensive_gaps` | 线间和防线空档候选 |
| `transition_analysis` | 夺失球后的推进、回追、反抢与恢复代理 |

分析器共享 GSR 上下文，各自执行规则/时序计算；不是一个“识别所有技战术”的端到端模型，也不表示逐篇复现了论文的训练过程。

## 网页与交付

- 素材上传、缩略图、素材库、项目列表与项目视频入口。
- 原视频人物/足球框选播放、拖动进度、事件节点、右侧片段筛选。
- 关键事件的观察、解释、建议、限制与前后取证画面。
- 确认/拒绝；采纳数、动作类型、定位球次数同步更新。上传任务记录保存于本地 runtime；历史演示的页面审核不等同于修改原始报告。
- 定位球按角球、任意球、球门球、界外球、中圈开球、点球分类计数并播放片段。
- JSON、Markdown、CSV，摘要、高光清单及相应导出脚本；部分双机位流程包含 PDF 报告。
- 桌面/移动响应式页面、HTTP Range 视频读取、处理状态与失败提示。

## 按需分析

| 功能 | 实现 | 限制 |
| --- | --- | --- |
| 阵型可视化 | `build_formation_evidence.py` 生成原图/框线图/短片，点击才显示 | 不补画外球员，几何分组不能当整场固定阵型 |
| 球员编号 | BoT-SORT、颜色约束、切镜隔离、网页可关闭编号 | 不是球衣号码，不承诺跨镜头身份；遮挡仍会换号 |
| 个人片段 | 选编号和最多 30 秒同镜头区间，导出视频、证据、统计 | 图像位移不是米制速度；新片段语义结论需复核 |
| 近景个人技术 | 姿态窗口、脚/头球候选、射门关键帧回看、门将分支、中文讲解 | 无法直接测肌肉发力、真实力量；不是教练级评分 |
| 远近景工作流 | `run_match_analysis_workflow.py` 扫描、镜头路由 | 尚未完成跨多场长比赛验收 |
| 双机位/俯视 | `analyze_projection_folder.py` 等结合位置 CSV、几何和视频，切换视图 | 需符合已有输入格式，不能把任意两个视频自动当同步标定输入 |
| 视觉模型 | Responses/兼容接口多帧复核、动态补证、门将复审、结构化评语 | 抽帧仍可能漏关键动作，模型意见不是人工真值 |

## 未完成与不承诺

正式校准 xG/xA/xT/EPV、完整 22 人 Pitch Control、可靠越位裁决、真实射门力量、稳定跨镜头实名身份、惯用脚长期统计、精确扑救成功率、复杂套路自动识别、教练级动作评分、战术生成，都未达到成熟产品级。没有充分结果标签和分母时，不应仅靠代理指标给出确定百分比。

尚缺：多场人工真值、检测/跟踪/事件准确率评测、标定误差评估、持续身份与可靠球轨迹、模型跨比赛泛化、长视频资源治理、公网认证部署。下一步以底层准确性和评测闭环为先，而非继续增加未经验证的指标。
