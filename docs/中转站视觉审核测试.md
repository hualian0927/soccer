# 中转站视觉审核测试

更新：2026-09-30。

## 测试范围

使用 `https://codeapi.icu/v1/responses` 请求 `gpt-5.6-terra`，复核已有五分钟原视频。
主画面复用已生成人物和足球检测框的完整视频；重新运行的是图像取证、事件复核、补证、门将复审、进攻组织与局部空间评语。
不是重新训练检测器，也不把旧助手结论当作模型输入或人工真值。

模型列表及返回模型标识只能证明平台声称的路由，不能独立认证其真实上游模型。
图片会发送给该第三方平台；数据保留政策与费用以该平台为准。

## 启动审核

```bash
conda activate sports
python -m workflows.review.run_openai_tactical_review \
  --bundle soccer_input_dataset/outputs/test_5min_layered_v2/layered_analysis.json \
  --baseline soccer_input_dataset/outputs/test_5min_layered_v4/layered_analysis.json \
  --output-dir soccer_input_dataset/outputs/test_5min_relay_terra_v1 \
  --base-url https://codeapi.icu/v1 --model gpt-5.6-terra \
  --reasoning-effort medium --no-cost-limit --max-calls 150 --prompt-key
```

终端隐藏输入中转站密钥。密钥不写入项目、报告、前端或 Git。
不设置金额上限；保留每次运行的请求数量、超时、有限重试与最多两次补证限制。
未知中转站价格不套用官方价格，账本的费用字段为 `null`，不表示免费。
接口使用流式响应减少长请求网关超时，只接收完整终态及符合 Schema 的结果。
高推理强度多图测试遇到超时，测试配置调整为 `medium`；并未减少初始图片或取消复审。
该调整未经过足球真值集验证，不能宣称准确性完全等价。

初始每节点前后各 5 秒、21 张图片；模型可请求加密、扩窗或局部裁剪。
门将独立复审；出界额外核对新越界过程。证据不足不进入采纳统计。
出界不意味着可以完全确认角球或其他定位球类型，仍需重启动作证据。

## 网页新上传素材

如需让后续网页上传也使用同一路径，在启动前端的终端配置：

```bash
read -rs -p 'Relay API key: ' RELAY_API_KEY
export RELAY_API_KEY
export RELAY_BASE_URL=https://codeapi.icu/v1
export RELAY_MODEL=gpt-5.6-terra
export RELAY_REASONING_EFFORT=medium
cd web_preview
npm run dev -- --host 127.0.0.1
```

必须同时设置中转站地址和独立的 `RELAY_API_KEY`。不把 `OPENAI_API_KEY` 转发给中转站。
新上传任务：本地检测跟踪 -> 身份修正 -> 检测框视频 -> 算法候选 -> 同一视觉复核脚本 -> 网页。
现有上传默认球衣配置适用蓝白样例，不是任意比赛自动适配。
相同五分钟文件仅在模型、服务地址、版本、视频指纹匹配且审核完整时复用结果。
不配置密钥也能查看已生成版本，但不代表新素材会自动调用此平台。

## 输出和对照

结果独立保存在 `soccer_input_dataset/outputs/test_5min_relay_terra_v1/`：

- `layered_analysis.json`：网页关键事件、统计、进攻组织、队形空间。
- `tactical_review.md`：观察、解释、建议及证据限制。
- `api_usage.json`：实际请求状态、返回模型、图片数、token 和响应 ID。
- `reviews/`：逐窗口结果及补证历史。
- `evidence/`：审核图片及上下文视频切片。
- `baseline_comparison.json`：与旧版本的差异，不是准确率评估。

粗扫每 30 秒最多提取一个事件，不是逐帧全事件识别；未开展人工真值盲测前，不能承诺达到旧助手或教练的准确率。
之前的官方 API 与助手版本均保留。

## Sol 接口对照测试

用户随后指定改用 `gpt-5.6-sol`，已停止 Terra 审核进程。以下均是实际接口调用，不是本地模拟。

| 测试 | 状态 | 说明 |
| --- | --- | --- |
| Sol 双图 + 简单 Schema | 成功 | 约 24 秒；返回模型标识 `gpt-5.6-sol`，能描述蓝白球队和右侧黑衣门将 |
| Sol 7 图 + 完整严格 Schema | 未成功 | 在流式等待期限内未取得可用完整结果 |
| Sol 7 图 + 提示词 JSON | 成功 | 完整审核对象通过本地 Schema、时间和证据引用校验 |
| Sol Chat Completions 7 图 | 未成功 | 约 100 秒返回 HTTP 504 |

7 图审核认为 206–210 秒门将触球证据不足，返回 `uncertain` 并请求加密采样，没有强行确认扑救。
请求账本位于 `soccer_input_dataset/outputs/relay_sol_json_probe/api_usage.json`。
双图测试位于 `soccer_input_dataset/outputs/relay_sol_probe/smoke_test.json`。
接口可用不等于完整五分钟复盘已生成，亦不代表准确性已与旧版本对齐。

兼容方式仅移除服务端强制 Schema 参数，改为提示词要求 JSON；本地仍执行完整 Schema 与视觉证据门控。
请求的 `max_output_tokens=6000` 在一次成功回复中未被中转站严格遵守，返回 13817 个输出 token；不能据该参数推断硬预算。
上述接口测试尚不能证明服务稳定性，真实上游模型仍无法独立认证。

Sol 后续命令采用独立目录，不能复用 Terra 或官方 Sol 的审核缓存：

```bash
python -m workflows.review.run_openai_tactical_review \
  --bundle soccer_input_dataset/outputs/test_5min_layered_v2/layered_analysis.json \
  --output-dir soccer_input_dataset/outputs/test_5min_relay_sol_v1 \
  --base-url https://codeapi.icu/v1 --model gpt-5.6-sol \
  --response-format json_prompt --reasoning-effort medium \
  --no-cost-limit --max-calls 150 --prompt-key
```

网页对应配置为 `RELAY_MODEL=gpt-5.6-sol`、`RELAY_RESPONSE_FORMAT=json_prompt`。
当前网页服务只用于查看现有结果，未携带中转站密钥自动处理新上传；需明确按前述步骤重启配置。
