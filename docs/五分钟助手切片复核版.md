# 五分钟助手切片复核版

## 版本用途

本版由 Codex 直接查看原视频的切片抽帧，形成新的复核意见，不调用 DeepSeek API。它用于与上一版的自动候选和模型意见对照，不是人工专家真值，也不是自动算法整体准确率评测。

- 网页：`http://localhost:4173/` → 项目 → **五分钟助手复核对照测试** → **五分钟助手切片复核版**。
- 输出目录：`soccer_input_dataset/outputs/test_5min_assistant_review_v3/`。
- 主视频：`test_5min_assistant_review.mp4`，完整 299.9 秒，保留原声和人物/足球框。
- 主视频画面复用上一版，不重新训练或运行检测；不同的是复核结论、节点时间、证据切片和分层报告。旧版文件与上传缓存没有替换。
- 全部逐条文字：输出目录内 `assistant_review_report.md`。

## 查验范围和结果

查验已有 17 个候选的时间序列联系图，每个通常查看 11 张来源帧；对传中、出界和门将等疑难处补看约 0.25 秒间隔的连续抽帧。另从同一切片中发现 1 个清楚的界外球开出，合计 18 条。

| 意见 | 数量 | 含义 |
| --- | ---: | --- |
| 助手支持 | 6 | 支持所述动作或过程；其中含新增界外球，不等于官方结果确认 |
| 助手改判 | 8 | 采用新的类型或更具体解释，不再使用原射门/扑救等描述 |
| 助手排除 | 3 | 保留误检记录供比对，不纳入采纳事件及定位球片段统计 |
| 仍待核实 | 1 | 中场多人争抢的具体触球归属不清楚 |

“6+8”不是识别准确率：类型已被修改，而且取样不是随机全场真值标注。全片仍可能有本次候选之外的遗漏事件。

## 网页变化

- 新建独立项目，保留原候选名称与原时间，方便比较。
- 新增“全部意见、采纳与改判、排除、待核实”筛选。
- 节点下可展开实际查验的来源帧；另提供按新时间重新裁剪的前后各5秒证据和41张回看图片。可回看的41张不等于每张都已被助手单独查验。
- 用户确认状态仍为“待审核”，助手不会替用户确认成真值。
- 定位球片段只保留本次采纳的界外球；被排除的角球候选仍可在事件审核记录中回看。
- L2仅统计本次切片；L3改为实际看过的三个组织过程；L4保留原几何候选并标注“本轮未复核”。

## 可复现文件

- `review_annotations/test_5min_assistant_v3.json`：逐条审核意见、依据时段和额外查看的帧索引。
- `workflows/review/prepare_assistant_review_sheets.py`：生成带来源时间的抽帧联系图。
- `workflows/review/build_assistant_review_version.py`：校验素材哈希、合并审核、重新剪辑证据、发布 JSON/Markdown/视频版本，无 API 调用。
- `tests/test_assistant_review_version.py`：验证来源保留、统计排除、重复记录检查及不冒充人工确认。

```bash
conda activate sports
python -m workflows.review.build_assistant_review_version \
  --source-bundle soccer_input_dataset/outputs/test_5min_layered_v2/layered_analysis.json \
  --annotations review_annotations/test_5min_assistant_v3.json \
  --video soccer_input_dataset/test_5min.mp4 \
  --boxed-video soccer_input_dataset/outputs/test_5min_layered_v2/test_5min_boxes.mp4 \
  --output-dir soccer_input_dataset/outputs/test_5min_assistant_review_v3
```

审核绑定源视频和源报告的 SHA-256，不能直接迁移到新视频。此版尚未将复核数据转为训练集，也没有改变底层人物归队、门将颜色或足球检测误差。
